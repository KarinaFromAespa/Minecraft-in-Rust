# Roadmap — where 26.2 fits

This directory is the 26.2 rewrite of the
[Minecraft-in-Rust](../../README.md) programme. The programme's plan — era
decomposition, the per-version pipeline, sequencing and gates — is in
[docs/ROADMAP.md](../../docs/ROADMAP.md) at the repository root, and every
version's status is indexed in [VERSIONS.md](../../VERSIONS.md).

26.2 was ported from the 26.3 base through the version-port pipeline; its
port record — what was run, the real harness profile, and what remains
blocked — is [PORT-NOTES-26.2.md](PORT-NOTES-26.2.md).

This file previously held the upstream horizon-rust project's roadmap. It
is not reproduced here: this programme is independent of that project, and
its plan lives in the document linked above.
